## How to Run

All notebooks are built for **Google Colab** — no local setup needed.

1. Open [colab.research.google.com](https://colab.research.google.com)
2. File → Open notebook → GitHub → paste this repo URL
3. Pick the notebook you want
4. Runtime → Run all

Each notebook installs its own dependencies in the first cell.
