## How to Run Any Notebook

All notebooks are designed for **Google Colab** — no local setup needed.

1. Open [colab.research.google.com](https://colab.research.google.com)
2. File → Open notebook → GitHub → paste this repo URL
3. Select the notebook you want
4. Runtime → Run all

Every notebook installs its own dependencies in the first cell.
